Allmodels provides a unified API that routes text‑to‑speech, speech‑to‑text, and real‑time voice models from multiple providers. Users can compare latency, pricing, and capabilities across models, enabling seamless integration of voice AI into applications. The platform offers a single endpoint for TTS, STT, and streaming voice, simplifying development and reducing vendor lock‑in.

**Areas:** Company · VoiceAI · TextToSpeech · SpeechToText · Real-Time

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Allmodels: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
